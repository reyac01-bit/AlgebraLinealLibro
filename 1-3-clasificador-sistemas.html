🎯 Clasifica cada sistema
Para cada sistema, decida si tiene solución única, infinitas soluciones o si es inconsistente (sin solución). La retroalimentación aplica el Teorema del rango: si Ran(A) = Ran(A|B) = n hay solución única; si Ran(A) = Ran(A|B) < n hay infinitas soluciones que dependen de n − Ran(A) parámetros; si Ran(A) < Ran(A|B) el sistema es inconsistente y S = ∅. Cada ronda consta de 10 preguntas de dificultad progresiva.
